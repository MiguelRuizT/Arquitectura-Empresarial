# Mapeo de las plantillas originales de The Open Group a los entregables nuevos

| Plantilla original aportada | Salida T&G v2.0 | Qué apartados se llenaron | Límites |
|---|---|---|---|
| Phase C – Information Systems Architecture / *Architecture Deliverables Phases C and D* | C-01 Architecture Deliverables | Listas de catálogos, matrices y diagramas recomendados de Data y Application; ubicación real, contenido y relación con vistas | No confundir artefactos Phase C con Phase D |
| Phase A / *Architecture Definition* | C-02 ADD | Purpose, Scope, Goals, Principles, Baseline, Target Data/App, gaps, impactos y transición | Technology Architecture pendiente |
| Phase B / *Architecture Requirements Specification* | C-03 ARS | Success Measures, Business/Application Service Contracts, interoperabilidad, standards, constraints, assumptions y AR verificables | Sin RF de sistema ni endpoints |
| Phase B / *Architecture Roadmap* | C-04 Architecture Roadmap | Candidate Components, Work Packages, riesgos, dependencias y propuesta de transiciones | Roadmap completo se consolida en Phase E |
| Preliminary / *Architecture Repository* | C-05 Architecture Repository | Landscape, Standards, Reference, Governance, Solutions y control de identificadores | No se publica en un repositorio externo automáticamente |
| Phase F / *Architecture Building Blocks* | C-06 ABB | Catálogo de ABB lógicos y contratos entre bloques, en calidad de candidatos | No declara Phase F desarrollada ni SBB seleccionados |

Las plantillas originales se conservan como **fuente proporcionada** fuera de este ZIP; se reutiliza su estructura formal y marcas de The Open Group. El archivo de salida NO es una publicación oficial o aprobada por The Open Group: es una adaptación docente, como se indica en las portadas.
