# Glosario breve

Architecture Capability: personas, proceso, gobierno y repositorio para hacer EA. Architecture Vision: visión de valor y Target de alto nivel que orienta B/C/D. Architecture Repository: custodia y recuperación de activos de arquitectura. Enterprise Continuum: clasificación de activos genéricos a específicos. Deliverable: producto formal revisable; artifact: catálogo, matriz o diagrama dentro de un deliverable; ABB: building block conceptual, SBB: realización concreta posterior. Concern: interés o preocupación de stakeholder. Viewpoint: reglas de construcción de una vista; view: representación para un concern. Baseline: estado actual validado; Target: estado deseado; Transition: estado intermedio. Gate: decisión formal para avanzar. IT/OT: tecnologías de información y operación.
